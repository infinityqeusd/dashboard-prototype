# OpenBook Analytics Dashboard Prototype

Visual-only frontend prototype of a UK stock market portfolio dashboard for OpenBook Analytics.

## Tech stack

- Vite
- React
- TypeScript
- TailwindCSS

## How to run

1. Install dependencies:

```bash
npm install
```

2. Start the dev server:

```bash
npm run dev
```

3. Open the local Vite URL shown in the terminal.

## What's included (visual-only)

- Premium dashboard UI layout for a UK portfolio experience
- Light theme (default) and optional dark theme toggle with `localStorage` persistence
- Auto-scrolling ticker ribbon (mock LSE-style tickers)
- Portfolio score card and UK-focused top stories panel
- Portfolio overview chart placeholder with time range selector UI
- AI agent prompt widget with rotating UK-stock suggestions
- "Most searched UK stocks" panel with sparkline placeholders
- Upcoming dividends table (mock data)

## Notes

- No backend/API integration
- No real-time data or click-through behavior
- All values, stories, and tables are mock data for UI/UX prototyping
